CODE CALCULATES · AGENTS INTERPRET · EVIDENCE DECIDES

숫자는 코드가 계산하고, AI 팀은 서로 다른 관점으로 논증한다

이 실험은 LLM에게 주가와 이동평균을 암산시키지 않는다. TradingAgents 저장소의 공식 데이터 도구가 먼저 수치를 고정하고, 기술·펀더멘털·뉴스·리스크 역할이 같은 증거를 읽어 결론을 경쟁시킨다. 최종 리포트보다 중요한 것은 그 결론을 다시 검사할 수 있는 구조다.

FOR STUDENTS

AI 팀을 쓴다는 것은 어려운 문제를 “계산·해석·반론·결정·검증”으로 나누는 일이다

주식 종목은 예시일 뿐이다. 센서 분석, 정책 검토, 과학 조사, 제품 의사결정에도 같은 원리를 적용할 수 있다. 결정적인 수치는 코드와 데이터 도구에 맡기고, LLM은 근거를 해석하고 반대 논거를 세우며 누락을 드러내게 한다. 마지막에는 실제 결과와 비교해 팀의 판단을 교정한다.

01

원본 프로젝트를 읽는다

TradingAgents의 분석가, 토론자, 트레이더, 리스크 팀과 LangGraph 상태 흐름을 문제 분해의 근거로 삼는다.

02

정확성 경계를 코드에 둔다

가격, OHLCV, RSI, MACD, ATR은 저장소 @tool이 계산한다. LLM이 수치를 만들지 않는다.

03

관점을 역할로 분리한다

기술, 펀더멘털, 뉴스/센티먼트는 병렬로 독립 분석하고 서로의 결론에 미리 끌려가지 않는다.

04

리스크를 결정 게이트로 둔다

리스크 트레이더가 세 리포트와 수치 원장을 읽고 강세·약세 양쪽을 논증한 뒤 시그널과 조건을 낸다.

05

공백이 행동을 바꾸게 한다

모르는 값을 채우지 않는다. 데이터 공백이 신뢰도, 포지션 크기, HOLD, 숏 배제 같은 실제 결정에 연결돼야 한다.

06

시간이 지난 뒤 채점한다

다음 가격과 실현 수익을 기록하고, 백테스트나 paper portfolio로 판단을 검증한다. 이번 Claude 런에는 아직 없는 단계다.

EVIDENCE AUDIT

최신 런에서 확인할 수 있는 것과 없는 것

확인됨: 00~05 파일, 저장 시각의 단계 순서, P0의 저장소 도구 원문, 각 판정과 Data Gaps.

확인되지 않음: 최신 디렉터리에는 별도 EXECUTION-FLOW.md, 에이전트 런타임 ID, task/message transcript가 없다.

따라서 “6개 산출물이 생성됐다”는 관찰 사실과 “워크플로 계약대로 각 에이전트가 실행됐다”는 해석을 구분해야 한다.

WHY HOLD MATTERS

팀의 성과는 강한 매수 신호가 아니라, 억지 결론을 거부한 데 있다

좋은 회사: 영업이익률 64%, FCF 마진 59.5%, 순현금 $41.9B라는 강한 펀더멘털.

나쁜 위치: $200.75는 $189.80~$214.39 박스 중앙이라 현재 진입의 손익비가 1.08:1.

남은 위험: $155B 약정, 고객 3사 매출 54% 집중, 옵션·포지셔닝·긴 OHLCV 공백.

결정: 강세론을 버린 것이 아니라 더 나은 가격이나 돌파 확인을 기다리는 HOLD.

DO NOT OVERCLAIM

이 팀 런이 아직 증명하지 못한 것

제품 전체를 실행하지 않았다. Python LangGraph의 토론, portfolio manager, checkpoint, memory 전체 경로가 아니다.

실제 주문이 없다. entry·target·stop은 분석 계획이며 거래소나 paper broker에 주문을 보내지 않았다.

수익성이 검증되지 않았다. 백테스트, 다음 가격, 실현 수익, SPY 대비 알파가 아직 없다.

62%는 적중 확률이 아니다. 리스크 트레이더가 HOLD 판단의 증거 품질을 표현한 내부 신뢰도다.

투자 자문이 아니다. 뉴스와 웹 자료는 시간이 지나며 바뀌고, 분석 기준일은 토요일이라 실제 최신 행은 2026-07-31이다.
