CLAUDE NATIVE TEAM ARTIFACT

TradingAgents 포크를 Claude 스킬과 팀으로 운영하는 공개판

이 페이지는 저장소의 .claude 폴더를 그대로 읽어 팀 정의, 에이전트, 스킬, 워크플로, 실제 팀 런 산출물을 보여준다. 핵심은 두 분석을 섞지 않는 것이다: 제품 코드는 tradingagents/의 Python LangGraph 파이프라인이고, 여기의 런타임 리서치 팀은 Claude Code 서브에이전트와 웹 검색으로 별도 리포트를 만든다.

CODEX COMMENT

이 팀이 하는 일

팀은 두 갈래다. 개발/유지보수 전문가는 agent, graph, data, LLM, memory, eval, upstream drift를 담당하고, 런타임 리서치 팀은 market, fundamentals, news/sentiment, risk/trade 네 역할로 종목 리포트를 만든다. 스킬은 코드베이스 사실과 절차의 단일 출처다.

LATEST RUN

이번 런에서 해결된 것

2026-08-01-NVDA 런은 NVDA를 네 명의 Claude 리서치 에이전트로 분석했다. 3명은 병렬 리서치, ta-risk-trader는 세 보고서 검증 후 순차 실행됐다. 특히 가격 앵커 불일치, 기술지표 출처 충돌, 뉴스와 셀사이드 의견의 괴리를 숨기지 않았다.

QUALITY READ

최종 리포트 수준

최종 산출물은 HOLD, 신뢰도 55%로 정리됐다. 기술적 분석은 Neutral, 펀더멘털은 Strong, 뉴스/센티먼트는 Mixed다. Data Gaps와 면책을 유지해 “강한 회사지만 지금 가격에서는 신규 BUY가 아니다”는 판단 근거를 보존했다.

BOUNDARY

남은 문제와 경계

이 팀 런은 공개 웹 기반 AI 리서치이지 투자 자문도 백테스트도 아니다. BUY/SELL/HOLD는 Python 파이프라인의 5단계 레이팅과 호환되지 않는다. 문서 안의 API 키 이름은 설정 설명이며 실제 비밀값은 공개하지 않는다.

DO NOT MIX

Python 파이프라인과 Claude 리서치 팀은 다른 실행물이다

Python LangGraph 파이프라인

tradingagents analyze, yfinance/Alpha Vantage/FRED, 12개 제품 에이전트, 5단계 Buy/Overweight/Hold/Underweight/Sell 레이팅, memory log와 백테스트 대상.

Claude 런타임 리서치 팀

.claude/agents/ta-*-analyst.md, WebSearch/WebFetch, 네 개 마크다운 리포트와 최종 종합, BUY/SELL/HOLD 서술 신호, 교육용 실행 기록.
